三、一次请求的调用链 以 GET /product 为例

  1. 页面发起调用
    productList.vue → api/productHttp.js: selectProductByPage()
  2. axios 拦截器附加令牌
    util/request.js：headers.authorization = sessionStorage['authorization']，baseURL /api
  3. Dev Server 代理
    :8082/api/product → pathRewrite 去掉 /api → :8888/product
  4. JWT 过滤器
    JwtAuthenticationTokenFilter：解析 token 取 userId → Redis 取 user:{id} → 写入 SecurityContext
    token 无效 / Redis 无登录态 → 直接写 401 JSON 返回，不进 Controller
  5. 路径级授权
    CustomAuthorizationManager：按 "GET /product" 查权限标识 → PermissionService.hasPermission()（权限集合含 *:*:* 直接放行）
    未登录 → entrypoint 401；已登录无权限 → AccessDeniedHandler 403
  6. 方法级授权 + 进 Controller
    @PreAuthorize("@ss.hasPermission('product:item')") → ProductController 构造器注入 ProductService（只认接口）
  7. 业务层
    ProductServiceImpl（common/service/impl）：@Transactional、组装 VO、必要时读写 RedisCache
  8. 持久层
    ProductMapper + resources/mapper/*.xml → MySQL（逻辑删除 del_flag）→ POJO 回填
  9. 统一返回
    ResponseResult.okResult(data) → 前端拦截器判 code===200；401 清登录态回登录页；其他弹 ElMessage

四、三个横向机制 横切在每个接口上的东西

鉴权双层

路径级：CustomAuthorizationManager（方法+路径 → 权限标识表，18 条）
方法级：@PreAuthorize("@ss.hasPermission('模块:操作')")
两层共用 PermissionService，规则只有一份；白名单里不许放带 @PreAuthorize 的接口。

日志写操作

Controller 方法标 @OperLog(module, type)
OperLogAspect.@Around → 落 sys_oper_log（密码脱敏）
业务事务回滚不影响日志落库；失败也记。

定时任务

OrderTimeoutTask每分钟·15 分钟未支付取消 + 回滚库存 + 退券
StatDailyTask1:30·汇总昨天 → 看板两张汇总表
SupplyChainTask预警 / 预测
