## 三、P1 已完成明细（2026-09-15）

### 后端（鉴权体系 + 权限管理）
- **安全框架**：Spring Security + JWT（jjwt 0.9.0）+ Redis 登录态；无状态会话，token 校验过滤器（请求头 `authorization`）
- **登录接口**：`POST /login`（返回 token+用户）、`GET /logout`、`GET /getInfo`（用户+权限标识+角色）、`GET /getRouters`（菜单树）
- **RBAC**：sys_user/user_role/role_menu 标准模型；`@PreAuthorize("@ps.hasPermission('模块:操作')")`；super_admin 直通；不登录访问 `/sys/**` 返回 401，越权返回 403
- **用户/角色管理**：`/sys/user`、`/sys/role` 标准 CRUD + 重置密码 + 角色分配菜单 + 全量菜单树查询
- **操作日志**：`@OperLog` 注解 + AOP 切面 → `sys_oper_log` 表（新增第 31 张表），密码字段自动脱敏
- **登录态机制**：Redis key `user:{id}` 存 LoginUser，TTL 24 小时与 JWT 一致

### 前端（登录 + 主框架 + 管理页）
- `util/request.js`：axios 实例 + 请求拦截（附 token）+ 响应拦截（统一 code 处理、401 自动回登录页）
- `store/userInfo.js`：Pinia 状态，sessionStorage 持久化
- `router/index.js`：路由守卫 + 按 `/getRouters` 动态注册路由（菜单配了就可见，没配就 404）
- `directives/hasPermi.js`：按钮级权限指令 `v-hasPermi="'sys:user:add'"`
- 页面：`views/Login.vue`（登录页）、`views/Menu.vue`（左菜单+顶栏+修改密码+退出）、`components/home.vue`、`components/sysUser.vue`（搜索/分页/新增/编辑/重置密码/删除/角色分配）、`components/sysRole.vue`（CRUD + 分配权限树）、`views/404.vue`
