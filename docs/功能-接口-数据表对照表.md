# 功能-接口-数据表对照表

> 用途：实验报告 / 答辩材料。接口由 Swagger（`docs/swagger-api-docs.json`，共 96 个操作）整理。
> 「登录」列：✅=需登录（消费者或后台），🔓=游客可访问；「权限」列 = `@PreAuthorize` 权限标识（不填即登录即可）。
> 所有接口统一返回 `ResponseResult<T>`；分页参数 `pageNum/pageSize`，返回 MyBatis-Plus `Page`。

## 1. 认证与注册

| 功能 | 接口 | 登录 | 主要数据表 |
|---|---|---|---|
| 账号密码登录（发 token） | POST /login | 🔓 | sys_user（登录态写 Redis `user:{id}`） |
| 消费者自助注册 | POST /register | 🔓 | sys_user、sys_user_role |
| 退出登录 | GET /logout | ✅ | Redis |
| 当前用户信息+权限集合 | GET /getInfo | ✅ | sys_user、sys_role_menu、sys_menu |
| 当前用户菜单树 | GET /getRouters | ✅ | sys_menu、sys_role_menu |
| 健康检查 | GET /health | 🔓 | - |

## 2. 用户与角色（系统管理）

| 功能 | 接口 | 权限 | 主要数据表 |
|---|---|---|---|
| 用户分页/详情/全部 | GET /sys/user、/sys/user/{id}、/sys/user/getAll | user:list（详情 user:query） | sys_user |
| 新增/修改/删除用户 | POST/PUT /sys/user、DELETE /sys/user/{ids} | user:add / user:edit / user:delete | sys_user、sys_user_role |
| 启用/禁用账号 | PUT /sys/user/{id}/status | user:status | sys_user |
| 用户角色 id 集合 | GET /sys/user/{id}/roleIds | user:query | sys_user_role |
| 管理员重置密码 | PUT /sys/user/respwd | user:resetPwd | sys_user |
| 本人修改密码 | PUT /sys/user/password | ✅ | sys_user |
| 角色 CRUD | GET/POST/PUT/DELETE /sys/role… | sys:role（增删改细分 :add/:edit/:del） | sys_role、sys_role_menu |
| 角色菜单分配 | GET/PUT /sys/role/{roleId}/menu | sys:role:setMenu | sys_role_menu |
| 菜单树 | GET /sys/menu/tree | sys:role | sys_menu |
| 操作日志（记录） | —（AOP 注解，无独立查询页，简化项） | - | sys_oper_log |

> 用户/角色/菜单相关接口另有**路径级授权表**（`CustomAuthorizationManager`，`ecom-system/config`）按「方法+路径」做同标识比对：白名单之外未登录一律 401，已登录按表比对权限（实验4 任务二）。
